# Step-by-Step SUMO Network Creation Guide

This guide walks you through creating a 4-lane traffic network in SUMO from scratch.

## Prerequisites

- SUMO 1.12.0 or higher installed
- Text editor (VS Code, Sublime, or any editor)
- Basic understanding of XML format

## Step 1: Create Node File (Junctions)

Create a file named `nodes.nod.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<nodes>
    <!-- Central intersection with traffic light -->
    <node id="J0" x="250.0" y="250.0" type="traffic_light"/>
    
    <!-- Boundary nodes (entry/exit points) -->
    <node id="N" x="250.0" y="750.0" type="priority"/>
    <node id="S" x="250.0" y="-250.0" type="priority"/>
    <node id="E" x="750.0" y="250.0" type="priority"/>
    <node id="W" x="-250.0" y="250.0" type="priority"/>
</nodes>
```

### Explanation:
- `id`: Unique identifier for each junction
- `x, y`: Coordinates in meters
- `type`: Junction type
  - `traffic_light`: Signalized intersection
  - `priority`: Unsignalized (priority rules)

## Step 2: Create Edge File (Roads)

Create a file named `edges.edg.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<edges>
    <!-- North to Junction (Incoming) -->
    <edge id="N_to_J0" from="N" to="J0" numLanes="4" speed="13.89" priority="13"/>
    
    <!-- Junction to North (Outgoing) -->
    <edge id="J0_to_N" from="J0" to="N" numLanes="4" speed="13.89" priority="13"/>
    
    <!-- South to Junction -->
    <edge id="S_to_J0" from="S" to="J0" numLanes="4" speed="13.89" priority="13"/>
    <edge id="J0_to_S" from="J0" to="S" numLanes="4" speed="13.89" priority="13"/>
    
    <!-- East to Junction -->
    <edge id="E_to_J0" from="E" to="J0" numLanes="4" speed="13.89" priority="13"/>
    <edge id="J0_to_E" from="J0" to="E" numLanes="4" speed="13.89" priority="13"/>
    
    <!-- West to Junction -->
    <edge id="W_to_J0" from="W" to="J0" numLanes="4" speed="13.89" priority="13"/>
    <edge id="J0_to_W" from="J0" to="W" numLanes="4" speed="13.89" priority="13"/>
</edges>
```

### Parameters:
- `id`: Unique edge identifier
- `from, to`: Start and end nodes
- `numLanes`: Number of lanes (4 for our network)
- `speed`: Maximum speed in m/s (13.89 m/s = 50 km/h)
- `priority`: Road priority level (higher = more important)

## Step 3: Generate Network File

Run the `netconvert` tool:

```bash
cd sumo_files
netconvert --node-files=nodes.nod.xml \
           --edge-files=edges.edg.xml \
           --output-file=4lane_network.net.xml
```

### What This Does:
- Combines nodes and edges
- Generates lane geometries
- Creates junction logic
- Calculates connection priorities
- Outputs complete network file

### Expected Output:
```
Success.
Network created with:
  - 5 nodes
  - 8 edges
  - 32 lanes
```

## Step 4: Verify the Network

Open in SUMO-GUI to visualize:

```bash
sumo-gui -n 4lane_network.net.xml
```

### What to Check:
- ✓ All 4 approaches have 4 lanes each
- ✓ Junction connections are correct
- ✓ Traffic light is present at J0
- ✓ Lane arrows show correct directions

## Step 5: Create Connection File (Optional)

For custom lane connections, create `connections.con.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<connections>
    <!-- Define specific lane-to-lane connections -->
    <connection from="N_to_J0" to="J0_to_S" fromLane="0" toLane="0"/>
    <connection from="N_to_J0" to="J0_to_E" fromLane="1" toLane="1"/>
    <!-- Add more as needed -->
</connections>
```

## Step 6: Create Traffic Light Logic

Create `traffic_lights.tll.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<tlLogics>
    <tlLogic id="J0" type="static" programID="0" offset="0">
        <!-- Phase 0: North-South Green -->
        <phase duration="42" state="GGGGrrrrGGGGrrrr"/>
        
        <!-- Phase 1: North-South Yellow -->
        <phase duration="3" state="yyyyrrrryyyyrrrr"/>
        
        <!-- Phase 2: East-West Green -->
        <phase duration="42" state="rrrrGGGGrrrrGGGG"/>
        
        <!-- Phase 3: East-West Yellow -->
        <phase duration="3" state="rrrryyyyrrrryyyy"/>
    </tlLogic>
</tlLogics>
```

### Signal State Encoding:
Each character represents one signal:
- `G`: Green
- `y`: Yellow
- `r`: Red

Order matches the connections generated by SUMO.

## Step 7: Advanced Network Features

### Add Lane-Specific Attributes

```xml
<edge id="N_to_J0" from="N" to="J0" numLanes="4" speed="13.89">
    <lane index="0" speed="13.89" allow="passenger"/>
    <lane index="1" speed="13.89" allow="all"/>
    <lane index="2" speed="13.89" allow="all"/>
    <lane index="3" speed="11.11" allow="truck bus"/>
</edge>
```

### Vehicle Classes:
- `passenger`: Cars
- `truck`: Trucks
- `bus`: Buses
- `emergency`: Emergency vehicles
- `all`: All vehicles

### Add Turn Restrictions

```xml
<connection from="N_to_J0" to="J0_to_E" fromLane="0" toLane="0" dir="l" state="o"/>
<!-- dir: s=straight, l=left, r=right, t=turnaround -->
```

## Step 8: Create Type Definitions

Create `types.typ.xml`:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<types>
    <type id="urban_arterial" priority="13" numLanes="4" speed="13.89"/>
    <type id="highway" priority="15" numLanes="4" speed="27.78"/>
    <type id="residential" priority="5" numLanes="2" speed="8.33"/>
</types>
```

Use in edges:

```xml
<edge id="N_to_J0" from="N" to="J0" type="urban_arterial"/>
```

### Visualize in SUMO-GUI

```bash

```

## Step 10: Troubleshooting

### Common Issues:

**1. "Unknown node" error**
- Check node IDs match in edges
- Verify node file is loaded

**2. "No connections found"**
- Ensure `from` and `to` nodes exist
- Check edge directions

**3. "Invalid speed value"**
- Speed must be in m/s
- Use positive values only

**4. Traffic light not appearing**
- Node type must be `traffic_light`
- Check TLL file references correct junction

### Debug Commands:

```bash
# Verbose output
netconvert --node-files=nodes.nod.xml --edge-files=edges.edg.xml \
           --output-file=network.net.xml --verbose true

# Show warnings
netconvert ... --log warnings.txt

# Check geometry
netconvert ... --geometry.remove false
```

## Complete Build Script

Create `build_network.sh`:

```bash
#!/bin/bash

echo "Building SUMO network..."

netconvert \
    --node-files=nodes.nod.xml \
    --edge-files=edges.edg.xml \
    --connection-files=connections.con.xml \
    --tllogic-files=traffic_lights.tll.xml \
    --type-files=types.typ.xml \
    --output-file=4lane_network.net.xml \
    --junctions.corner-detail 5 \
    --junctions.limit-turn-speed 5.5 \
    --verbose true

echo "Network built successfully!"
echo "Open with: sumo-gui -n 4lane_network.net.xml"
```

Make executable:
```bash
chmod +x build_network.sh
./build_network.sh
```
